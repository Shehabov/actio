# BUGS.md

The defect register for Actio's product code. **Scope: defects in product code under `web/`,
`extension/` and `supabase/`, and in shipped content. Not agent or swarm mistakes.**

`bug-historian` owns this file and is the only agent that writes to it. It reads it at the
start of every run to brief the swarm on what has already gone wrong on the surface being
touched. A defect that repeats is worse than one that is new, because it means the register
was written and nobody read it.

---

## How to use this file

| You are | Do this |
|---|---|
| Shehab | Raise any product defect. One line is enough. `bug-historian` fills in the rest. |
| `qc-engineer` or `qc-lead` | Report the defect in your handoff with reproduction steps and the evidence path. |
| Any other agent | Do not edit this file. Report the defect to `bug-historian` in your handoff. |
| Any agent starting a run | Read the entries your brief names for the surface you will change, before you plan. |

---

## Entry format

Every entry is one block of at most 40 lines. Never delete an entry: close it, and keep it.
Dated detail lives in `.actio/bugs/history/BUG-NNNN.md`.

````markdown
### BUG-NNNN · One line saying what broke, sentence case

| | |
|---|---|
| Status | open |
| Raised by | qc-engineer |
| Raised on | 2026-10-07 |
| Run | 2026-10-07-issue-reassignment |
| Surfaces | db, issues |
| Component | `supabase/migrations/20261007120000_close_guard.sql` |
| Agent at fault | backend-engineer |
| Class | state-machine |
| Severity | blocker |
| Evidence | `.actio/runs/2026-10-07-issue-reassignment/evidence/qc/close.log` |
| Binds | backend-engineer, code-analyst, qc-engineer |
| Rule | none |
| Repeat of | none |
| History | `.actio/bugs/history/BUG-NNNN.md` |

**What happened.** The observable product defect, in at most four lines.

**Why it got through.** The gate that should have caught it, and the hole in that gate.

**The rule this produces.** The class-level rule, or "None new".

**How to detect it next time.** One line saying what the block checks.

```detect
stack: sql
git grep -nE "update issue set status *= *'closed'" -- supabase/migrations
```
````

| Field | Why |
|---|---|
| `Surfaces`, `Binds` | Drive every later brief. Tags come only from `.actio/bugs/surfaces.json`; `Binds` names the roles that must change behaviour |
| `Agent at fault` | Routing, not blame. Where the brief or spec was wrong, say so |
| `Repeat of` | The earlier id when this is the second occurrence. A third escalates to Shehab |
| `detect` block | One block, runnable and read-only, proved with `bugs.mjs proof` before it is published |

## Classes

| Class | Means |
|---|---|
| `privacy-invariant` | Threshold, filtering, free text, protected cases. The most serious class. |
| `state-machine` | Closure without evidence, illegal transition, lane without authority. |
| `contract` | Front end and back end disagreed about the API shape. |
| `correctness` | A plain bug: logic, null, boundary, timezone, race. |
| `security` | Authorisation, injection, secrets, personal data in a log or a URL. |
| `data-layer` | N+1, missing index, unbounded query, migration lock, non-reversible migration. |
| `brand` | A token, contrast, type, spacing, motion or copy rule broken in shipped UI. |
| `design-system` | Shell, inversion rule, component anatomy, density, state coverage. |
| `locale` | Arabic, RTL, length, plurals, a string concatenated with a count. |
| `accessibility` | Contrast, focus, target size, colour as the sole carrier, screen reader. |
